# Отчёт по подготовке демо "Медицинский мониторинг"

- Время: 05.02.2026 14:00
- Аналитик: Иванцов Максим

---

## Выявленные риски:

1. **Критический:** Отсутствие конкретных критериев «опасных значений» для системы предупреждений — демо может показать некорректные алерты
2. **Высокий:** «Безопасное хранение данных» без технических спецификаций — прямое нарушение 323-ФЗ о врачебной тайне
3. **Средний:** «Интеграция с ЕГИСЗ» без определения объема и формата данных — риск невыполнения законодательного требования

---

## Принятые меры:

- Сфокусировали демо на 3 ключевых сценариях: дашборд врача, система предупреждений, история пациента
- Реализовали костыли: синтетические данные, захардкоженные правила алертов, неактивная кнопка ЕГИСЗ
- Создали детальный демо-скрипт с четкими переходами и границами показа
- Скрыли рисковые функции (ввод симптомов, экспорт данных) из интерфейса демо-версии

---

## Рекомендации на будущее:

1. Ввести обязательное поле «Критерии приемки демо» для каждого требования
2. За 24 часа до демо проводить Pre-Flight Check по контрольному чек-листу
3. Разработать встроенный «режим презентации» в приложении с заранее подготовленными данными
4. Создать библиотеку синтетических медицинских данных для тестирования и демонстраций
