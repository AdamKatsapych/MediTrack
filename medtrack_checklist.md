# Чек-лист верификации демо "Медицинский мониторинг"

## ПОДГОТОВКА ДЕМО-СРЕДЫ
-  Созданы 3 тестовых пациента с синтетическими данными
-  Для пациента "Сидоров С.С." настроены "опасные значения" (пульс > 120)
-  Настроен демо-аккаунт врача (логин: doctor01, пароль: demo2024)
-  Отключены все недемо-функции (ввод симптомов, экспорт, фото)
-  Кнопка "Интеграция с ЕГИСЗ" отображается как неактивная
-  Приложение протестировано на эмуляторе старого Android

## БЕЗОПАСНОСТЬ И СООТВЕТСТВИЕ
-  Все демо-данные синтетические (Иванов, Петров, Сидоров)
-  Предупреждение срабатывает только при пульсе > 120
-  История болезни доступна только авторизованному врачу

## ПРОИЗВОДИТЕЛЬНОСТЬ
-  Загрузка дашборда врача: < 3 секунд
-  Переключение между пациентами: < 1 секунды
-  Отображение графика: < 2 секунд
-  Проверена работа при слабом сигнале Wi-Fi

## СЦЕНАРИЙ ДЕМО
-  Вход врача проходит успешно с первого раза
-  Дашборд отображает 3 пациента
-  У пациента Сидорова видно красное предупреждение
-  При клике на предупреждение открываются детали
-  История болезни отображает все записи
-  Проверен вход с неверным паролем (должна быть ошибка)
-  Проверено нажатие на неактивную кнопку ЕГИСЗ (должно быть сообщение)
